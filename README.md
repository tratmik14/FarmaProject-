# CIP Контроль

Учебная демонстрация проекта Шимарова Тихона Сергеевича «Автоматизация сбора данных по простоям в фармацевтическом производстве».

Сайт: https://tratmik14.github.io/FarmaProject-/

Статический HTML/CSS/JavaScript, без сборки. Актуальные файлы — index.html, css/ и js/. Сценарии синтетические, прогноз эвристический. Все записи хранятся в браузере. Реального оборудования, обученной модели и промышленного соответствия GMP нет. Карточки разбора не являются решением о выпуске серии.

Локально: python -m http.server 8080, затем http://localhost:8080/. Проверки: node tests.mjs. Проверки DOM выполняются с учебным адаптером, не заменяют проверку в браузере.

Фото CIP в разделе проекта: INOXPA, https://www.inoxpausa.com/products/systems/cip-systems/cip-cleaning-pharmaceutical-industry . Иллюстрация, не площадка внедрения.

Локальная контрольная точка обнаруживает отдельную подмену или удаление записей. Одновременная подмена всех данных браузера требует независимого доверенного контура и здесь не предотвращается.
