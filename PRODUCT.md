# CIP Контроль

Учебный сайт проекта Шимарова Тихона Сергеевича. Задача — демонстрация учёта простоев одного узла фармацевтического производства на примере CIP-станции. Аудитория: конкурсная комиссия, студент и преподаватели. Сохранены синтетическая телеметрия, профили, эвристика, локальный журнал и карточки разбора. Добавлены баланс времени и CSV. Реального оборудования, обученной модели и промышленного соответствия GMP нет. Данные остаются в браузере. Размещение — статический GitHub Pages.
